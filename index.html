Security by Architecture, Not Afterthought

Exposing a dev environment to web AI requires uncompromising defense-in-depth.

🛡️

Cryptographic Bearer Auth

Every single HTTP and SSE endpoint is guarded by a high-entropy 256-bit authentication token. Requests without matching Bearer headers or query tokens are dropped immediately with HTTP 401 Unauthorized.

🗂️

Chrooted Path Sandbox

All file system operations are strictly resolved against the designated workspace root. Directory traversal attacks (../, symlink hopping) to ~/.ssh or /etc/passwd are strictly blocked and logged.

⚙️

Shell Execution Controls

Command execution includes configurable per-process timeouts (default 30s) and head-tail log truncation. The terminal execution tool can be completely disabled on the fly via enable_command_execution: false.
